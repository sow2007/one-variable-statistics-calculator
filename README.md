# one-variable-statistics-calculator

This program helps to save a little bit of time with basic analysis by able to calculate the mean, median, percentiles, and other one-variable statistics of an array of data!

Use the .bat file to open the program. If you insist on using it in R Studio, only 'calculator studio.R' will work.

Data can either be imported from a .csv file or manually imported.

# Notes
- For importing data, data *must* be in a .csv file format. I will perhaps work on supporting other file formats in the future.
- For importing data, as of now, when entering the path to your .csv file, you must not include any quotation marks that surround the file location. At least for Windows 11, these quotations are there by default when you simply select "Copy as path".
- There is no error-checking on this right now. I will update this very soon to ensure that the program doesn't just crash becasue the user accidentally entered the wrong type of data.
